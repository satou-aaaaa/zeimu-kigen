# 税の期限（zeimu-kigen）

相続税の申告、亡くなった人の所得税の申告、会社の法人税・消費税の申告、払いすぎた税を直す更正の請求、税の処分への不服申立て、赤字の繰越し、相続の前の贈与の加算、税の時効などの場面を読んで、その期限（1か月・2か月・3か月・4か月・10か月・1年・3年・5年・7年・10年）を当てる1日5問の学習ゲーム。正解したら、どのきまりか（申告の期限／直す・不服／繰越し・さかのぼり）も選ぶ。税のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/zeimu-kigen/>

- 中身は e-Gov 法令検索の国税通則法（<https://laws.e-gov.go.jp/law/337AC0000000066>）第23・70・72・77条、所得税法（<https://laws.e-gov.go.jp/law/340AC0000000033>）第70・124・125・144条、相続税法（<https://laws.e-gov.go.jp/law/325AC0000000073>）第19・27・32・38条、法人税法（<https://laws.e-gov.go.jp/law/340AC0000000034>）第57・74・75条の2、消費税法（<https://laws.e-gov.go.jp/law/363AC0000000108>）第45条に書いてある期限だけです（2026-11-18 に読んだ今の条文）。
- 説明は条文を、短く言いかえたものです。税の金額・税率、地方税、租税特別措置法の特例、期限が休日にあたるときの扱いは省いています。公式の情報の代わりではありません。実際のことは、国税庁の案内、専門家に確かめてください。
- 2段目は、きまりの種類で分けています。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
